# Career Coach (local)

Generated from the bundled Reactive Resume skills. Original MIT notices and adaptation sources are included.

Connection: http://localhost:3110/mcp. Sign in to the local app to grant account access. No credentials are included in this package. No local AI model is started or configured. The Codex host processes its conversations; app AI tools require a separately configured cloud provider.

Use the evidence-interview skill first. Current tool discovery is authoritative. Evidence approval never authorizes application submission.

For installation, usage, attribution and companion requirements, see [the repository README](../../README.md). The companion checkout's `node tooling/local/package-plugin.mjs` command can regenerate the original local package; that command and the companion source are not included in this plugin-only repository.
